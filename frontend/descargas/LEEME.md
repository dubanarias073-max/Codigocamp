# Descargas

Pon aquí `CodigoCamp.apk`: la app de Android (CódigoCamp completo + el widget de racha). Cuando el archivo existe,
aparece el botón «Descargar la app para Android» en la portada (página de inicio) y en Configuración → App y widgets.

Cómo conseguir el APK sin instalar Android Studio: sube el proyecto a GitHub, abre la pestaña **Actions** →
**App de Android** → la última ejecución → **Artifacts** → `CodigoCamp-apk`. Descomprime el .zip y copia
`CodigoCamp.apk` en esta carpeta. (Si tenías `CodigoCamp-Widget.apk`, bórralo: ya no se usa.)
