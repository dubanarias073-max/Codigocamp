# Descargas

Pon aquí `CodigoCamp-Widget.apk` (el widget de Android). Cuando el archivo existe, Configuración → App y widgets
muestra el botón «App del widget para Android».

Cómo conseguir el APK sin instalar Android Studio: sube el proyecto a GitHub, abre la pestaña **Actions** →
**Widget de Android** → la última ejecución → **Artifacts** → `CodigoCamp-Widget-apk`. Descomprime el .zip y copia
`CodigoCamp-Widget.apk` en esta carpeta.
